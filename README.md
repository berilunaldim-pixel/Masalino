# Masalino
**Her renk başka bir masal anlatır.**

## Proje Hakkında
Masalino, Programlamaya Giriş dersi kapsamında HTML, CSS ve JavaScript kullanılarak hazırlanmış, Türk masallarını bir araya getiren interaktif bir web sayfasıdır.

Projenin amacı, bu üç teknolojiyi birlikte kullanarak okunabilir, kullanıcı dostu ve işlevsel bir web arayüzü geliştirmektir.

## İçerik ve Özellikler
Web sitesinde sekiz Türk masalı bulunmaktadır. Kullanıcılar masalları seçebilir, arama yapabilir, çocuk ve yetişkin anlatımları arasında geçiş yapabilir ve yazı boyutunu değiştirebilir.

Tasarımda masal temasına uygun renkler ve özgün çizimler kullanılmıştır. Sayfa, telefon ve bilgisayar ekranlarına uyumludur.

## Kullanılan Teknolojiler
- HTML5: Sayfanın yapısı ve içerikleri
- CSS3: Görsel tasarım ve ekran uyumu
- JavaScript: Arama, masal seçimi, gezinme ve okuma ayarları

CSS ve JavaScript kodları tek HTML dosyasında yer almaktadır. Sayfa internet bağlantısı olmadan çalışacak şekilde hazırlanmıştır.

## Çalıştırma
`index.html` dosyasını indirip bir web tarayıcısında açmak yeterlidir.
